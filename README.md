# hippo2coding.github.io

김성재(hippo2coding)의 포트폴리오 사이트입니다.
👉 https://hippo2coding.github.io

SK Networks Family AICAMP 28기(2026.03–08) 과정에서 진행한 다섯 개의 팀 프로젝트를
에이전트 런타임 · RAG 파이프라인 · 평가 엔지니어링 세 축으로 정리했습니다.

## 구성

- `index.html` — 포트폴리오 본문 (정적 HTML 단일 파일, 외부 의존성은 Google Fonts뿐)
- `assets/` — 프로젝트 화면 및 기획 산출물 이미지

## 로컬에서 보기

python -m http.server 8000
